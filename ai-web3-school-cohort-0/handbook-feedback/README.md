# Handbook Feedback

Use this directory to collect feedback that can be indexed, reviewed, and later submitted upstream.

Each feedback item should include:

- Handbook page URL.
- Topic or section.
- Problem type: typo, unclear concept, outdated link, missing example, structure suggestion, translation issue, or other.
- What is confusing or incorrect.
- Suggested improvement.
- Source: daily note, task, experiment, or discussion.

## Workflow

1. Capture the issue while studying.
2. Create a feedback note from `templates/handbook-feedback.md`.
3. Link the feedback item from the related daily note.
4. Review before submitting upstream.
5. Record the upstream issue/PR/link when submitted.
